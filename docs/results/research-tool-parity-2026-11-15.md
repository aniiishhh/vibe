## Exposed capabilities

- Class search accepts keyword and instructor queries without a catalog number. Search/discovery expose subject/course, numeric level, campus, campus-vs-online delivery, iCourse/ASUSync location, session, days, start/end dates, units, college, open/all, honors and program filters. Arguments are allowlisted, translated to the existing ASU client parameters and bounded to two pages. Returned normalized sections retain source links. Level and explicit course matching are checked locally as well.
- Syllabus lookup starts with the requested semester (including an upcoming semester when supplied). The existing upstream ranking prefers that professor's current syllabus, then that professor's syllabi across six earlier terms, then other professors. An explicit fallback list overrides the default; an empty list requests current-only. The prior adapter always supplied an empty default and thus disabled history; that bug is fixed.
- Historical/different-instructor/partial syllabus metadata remains in the evidence and is also surfaced as visible warnings. Citations use the actual source term, with the requested-term link retained separately. Page-labelled excerpts are bounded to 6,000 characters without duplicating the same text in another field. The lookup has a 60-second budget within the existing 90-second Lambda timeout. Missing, partial and unavailable results retain those states; they do not establish current grading or workload. Transient/partial syllabus failures are not cached.
- RMP supports general professor metrics/reviews and course-specific review samples. Overall professor metrics remain separate from course-sample helpfulness, clarity and difficulty averages/counts. The default is two pages of ten reviews; up to six pages and an opaque continuation cursor are available when needed. Responses retain coverage, cursor and sample/returned counts. A course missing from a bounded sample is not claimed to have no reviews anywhere. Bare-number reviews without a department are not treated as an exact course match.
